# Desktop-Camera-KMP
It's a personal project intended to create a Desktop App using KMP to visualize webcam and transmit it using rtsp, among other things described below.

## Learning Goals
 - KMP
 - Rust
 - MSMF (Microsoft Media Foundation)
 - uniffi (to generate bindings from rust to kotlin)

## Project Goals
 - Visualize camera (done)
 - RTSP support
 - Take shots
 - Record videos
